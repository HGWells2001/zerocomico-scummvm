ZERO COMICO - SCUMMVM CUSTOM BUILD
=================================

Questo pacchetto contiene ScummVM compilato con il motore sperimentale
nativo Zero Comico.

NON contiene i dati originali del gioco.

INSTALLAZIONE
-------------
1. Installa questo pacchetto.
2. Avvia "Configura Zero Comico" dal menu Start, oppure usa il collegamento
   creato dall'installer.
3. Inserisci il percorso della tua installazione retail di Zero Comico.
4. La cartella deve contenere almeno:
     Zero Comico.exe
     Config.gsc
     Mp0 ... Mp5
     Mpx
     images
     Music
     Sound
     Speech

VIDEO
-----
Per intro e filmati, copia anche la cartella Data dal CD originale nella
cartella dati del gioco. Senza Data il motore può avviarsi ma salterà i
filmati mancanti.

VERSIONE
--------
Il file BUILD-INFO.txt indica il commit esatto del motore e la sorgente
ScummVM usata dalla build automatica.

NOTA
----
Il motore è in fase di validazione end-to-end. Conserva i salvataggi di
test e segnala il primo blocco di progressione incontrato.
